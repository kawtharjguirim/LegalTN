## 3. Ce que l'IA n'a PAS fait

À confirmer par l'équipe, par exemple :

- [ ] aucune annotation gold (obligations, NER, alignement) produite par une IA ;
- [ ] aucune question de référence (dev ou test) rédigée par une IA ;
- [ ] aucune mesure sur le test gelé lancée pour régler un paramètre ;
- [ ] aucun chiffre du rapport non retrouvable dans `experiments.md`.
